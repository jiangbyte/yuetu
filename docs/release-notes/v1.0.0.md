# 月兔 v1.0.0

首个公开发布：本地优先的笔记 · 任务 · 记账 Android App。

## 功能

- 流水：月度汇总、收支筛选、分类、搜索、支付方式、无限滚动
- 日历：月历标记流水 / 任务，查看当日明细
- 事项：任务与笔记合一；日期、优先级、分类筛选
- 报表：ECharts 收支分析
- 我的：分类管理、数据维护、关于（含技术栈 / GitHub / 作者）

## 技术

- Taro 4 · React · TypeScript
- 本机 SQLite（H5：sql.js + IndexedDB）
- Capacitor 包装 H5 产物为 Android APK

## 安装

下载 Release 附件 `yuetu-v1.0.0.apk` 安装即可。

仓库：https://github.com/jiangbyte/yuetu
