# 月兔 v2.0.0

全面切换到 Flutter：本地账本与事项能力对等重写，Android / iOS 原生壳。

## 亮点

- 技术栈改为 Flutter · Riverpod · Drift · go_router
- 功能对等：流水、日历、事项/笔记、报表、分类、数据导出清空
- 企业级 feature-first 目录结构
- 底部 Dock 扇形快捷：记一笔 / 加任务 / 写笔记
- 月光纸感主题延续
- GitHub Actions 自动构建并发布签名 release APK

## 说明

- 旧 Capacitor / WebView 本地数据不迁移；新安装从空库 + 默认分类开始
- 可用「我的 → 数据管理」导出 JSON 备份

## 安装

下载 Release 附件 `yuetu-v2.0.0.apk` 安装即可。

仓库：https://github.com/jiangbyte/yuetu
